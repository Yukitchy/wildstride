# 04 デザインの決めごと

**このファイルで分かること**
「なんかAIが作ったっぽいな」を消すための具体的なルールと、その理由。
デザインの勉強をする話ではなく、**プロンプトに書き足す一言**の話です。

---

## まず、AIっぽさとは何か

放っておくとAIは毎回だいたい同じものを作ります。見た人はそれを見慣れているので、
中身を読む前に「ああ、AIね」と処理してしまいます。**信用の問題**です。

具体的にはこの6つ。心当たりがあるはずです。

| よく出るやつ | なぜダメか |
|---|---|
| **紫から青のグラデーション** | AIが作ったページの定番中の定番。見た瞬間にバレます |
| **クリーム色の背景 + 明朝体（セリフ）+ テラコッタ色** | 「上品にして」と言うと必ず出る組み合わせ。これも定番化しました |
| **全部が中央寄せ** | 文章が読みにくい。目が毎行の頭を探すので疲れます |
| **全部の角が同じ丸み（12px）** | どれも同じ形なので、どこが大事か分からなくなります |
| **見出しに絵文字** | 🚴 ✨ 🌊 が並ぶと、内容の重みが軽く見えます |
| **どれも同じ大きさの文字** | 強弱がないので、上から全部読まないと要点が分からない |

> **セリフ体**＝明朝体のように、文字の端に飾りがついた書体。
> **サンセリフ体**＝ゴシック体のように、飾りのない書体。

## 守ると良くなる7つのルール

プロンプトに書くだけです。

### 1. 文字は左揃えを基本にする
理由：文章は左端が揃っていないと読めません。中央寄せは**タイトルなど1〜2行のものだけ**。

### 2. 見出しは本文の2倍以上の大きさにする
理由：差が小さいと、ぱっと見でどこが要点か分かりません。
差は大げさなくらいでちょうどいいです。中途半端が一番読みにくい。

### 3. 色は3〜4色まで
理由：色を増やすほど、どの色が「大事」を意味するのか分からなくなります。
背景・文字・アクセント1色。これで足ります。

### 4. 書体は2種類まで
理由：3種類以上になると統一感が消えます。
見出しと本文で分けるか、いっそ1種類で大きさだけ変えるほうが締まります。

### 5. 余白を惜しまない
理由：詰め込むと安っぽく見えます。**情報を減らすより、余白を増やすほうが早い**です。

### 6. スマホの縦持ちで確認する
理由：ゲストはほぼ全員スマホで見ます。PCで綺麗でもスマホで崩れていたら意味がない。
PCで作ったら、必ず自分のスマホでも開いてください。

### 7. 明るい画面と暗い画面の両方で見る
理由：スマホの設定で背景が黒くなる人がいます（ダークモード）。
そこで文字が読めなくなるページはよくあります。
プロンプトに「明るい表示でも暗い表示でも読めるようにしてください」と足すだけで防げます。

## 「良くない」と思ったときの言い方

「なんかダサい」だけでは直りません。**どこが・どうなってほしいか**を1つずつ言います。

| ✗ 効かない言い方 | ○ 効く言い方 |
|---|---|
| もっとおしゃれにして | 色を3色に減らして、余白を今の1.5倍にしてください |
| なんか違う | 上品にしようとして弱くなっています。もっと骨太に、文字を大きくしてください |
| 読みにくい | 本文の文字が小さいです。スマホで読む前提で一段大きくしてください |
| ダサい | 見出しと本文の大きさが近すぎて、要点が分かりません。差をつけてください |

一度に全部言わず、**一つ直しては見る**を繰り返すのが結局いちばん速いです。

## 写真について、正直なところ

Claude が会話の横に出すページ（アーティファクト）には、
**外に置いてある画像やフォントを読み込めないという制約があります**。
つまり、自分の写真をそのままページに載せることは、この方法ではできません。

なので、こう分けて考えてください。

- **文章・構成・見た目の設計** → AIが得意。ここを任せる
- **写真を実際に埋め込んだ、人に渡せる形にする** → ユウキに頼んでください。すぐやってくれます

Wildstride のデモアプリに写真と動画が36点入っているのは、そこをユウキがやったからです。
masaya さんはページの中身を作るところまでで大丈夫です。

なお、**写真をAIに見せて文章を書かせる**のは普通にできます
（`02_プロンプト集.md` の5本目）。読ませるのはOK、ページに載せるのが別工程、ということです。

## 最後に一つ

デザインで一番効くのは、実は色でも書体でもなく、**削ること**です。
入れたい情報を全部入れたページは、ほぼ確実に読まれません。

ツアーの荷造りと同じで、迷ったものは置いていく。それだけで見違えます。
