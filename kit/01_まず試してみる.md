# 01 まず試してみる — 5分で1枚

**このファイルで分かること**
直近のツアー1本を題材に、ゲストに渡せる「記録ページ」を1枚つくるところまで。
説明は後回しで、まず1つ完成させます。読みながら手を動かしてください。

---

## 準備（1分）

思い出せる範囲で、直近のツアー1本について次を頭に浮かべてください。メモは要りません。

- ツアーの名前（無ければ「◯◯から△△まで」で可）
- 何日間か / 何日目にどこからどこまで走ったか
- だいたいの距離
- ゲストの人数と、どこの国から来た人か
- 印象に残っている場面3つ（天気、坂、飯、ゲストの一言、なんでも）

**この時点で正確でなくて構いません。**
あとから直せます。むしろ最初から完璧を目指すと止まります。

---

## 手順（4分）

### 1. Claude を開く

https://claude.ai を開いてログインします。

### 2. 新しい会話をはじめる

左上あたりの「新しいチャット」を押します。
**1つの作りものにつき1つの会話**にしてください。話題を混ぜると精度が落ちます。

### 3. 下のプロンプトを丸ごとコピーして貼る

`【ここを書き換える】` の部分だけ自分の内容に置き換えてから送信します。
それ以外はいじらなくて大丈夫です。

```
あなたは旅の記録を1枚のWebページにまとめるのが得意なデザイナーです。
私は自転車のアドベンチャーツアーを本業でガイドしています。

いま終わったツアーの記録ページを、ゲストに渡せる形で1枚作ってください。
アーティファクト（会話の右側に表示されるページ）として出してください。

## ツアーの情報
- ツアー名: 【ここを書き換える：例 Setouchi Traverse】
- 日程: 【ここを書き換える：例 2026年5月10日〜5月14日、5日間】
- ルート: 【ここを書き換える：例 1日目 尾道→今治 70km / 2日目 今治→松山 55km / ...】
- 総距離: 【ここを書き換える：例 約320km】
- ゲスト: 【ここを書き換える：例 オーストラリアから2名、シンガポールから1名】
- 印象に残った場面3つ:
  1. 【ここを書き換える：例 来島海峡大橋の上で全員が自然に足を止めた】
  2. 【ここを書き換える：例 2日目の雨で予定を変えて内子の宿に早入り、結果的にそこが一番よかった】
  3. 【ここを書き換える：例 最終日、一番不安がっていたゲストが先頭を引いた】

## 作りかたの条件
- 縦に読み進める1枚のページ。上から「タイトル」「ツアーの概要」「日ごとの記録」「締めの一言」の順
- 日ごとの記録は、距離や地名などの事実と、その日の情景を1〜2文ずつ
- 文章は私（ガイド）の視点で、誇張せず落ち着いた調子で
- 写真はまだ入れないでください。文字と余白だけで成立させてください
- 見た目のルール:
  - 文字は左揃えを基本にする（中央寄せを全部に使わない）
  - 色は3〜4色まで。紫から青のグラデーションは使わない
  - 見出しは本文の2倍以上の大きさにして、強弱をはっきりつける
  - 見出しに絵文字を使わない
  - 角の丸みを全部同じにしない
  - スマホの縦持ちで読みやすいこと
- 私が渡していない数字（正確な標高、費用、参加人数など）は勝手に作らないでください。
  必要なら「ここに入れる情報」と空欄で示してください
```

### 4. 出てきたページを見る

30秒ほどで、会話の右側にページが表示されます。これが**アーティファクト**です。

> **アーティファクト**＝Claudeが作ったページを、会話の横でそのまま表示してくれる機能。

スマホなら、下か上に切り替えボタンが出ます。

### 5. 直す

たぶん一発では気に入りません。それが普通です。会話の続きに一言書けば直ります。

```
2日目の雨の話をもっと前に出してください。あれがこのツアーの山場でした。
```

```
全体的に文字が小さいです。スマホで読むことが多いので、本文をもう一段大きくしてください。
```

```
締めの一言が説明くさいです。ゲストが読んで、また来たいと思う終わり方にしてください。
3案出してから、いちばん静かなものを選んで入れてください。
```

**遠慮なく何度でも言ってください。** 回数を重ねるほど良くなります。

## つまずいたとき

**ページが出てこない / 文章だけ返ってきた**
→ 「アーティファクトとして1枚のWebページで出してください」ともう一度言えば出ます。

**途中で止まった / 「続けて」と言われた**
→ 「続きをお願いします」と送れば再開します。作り直しにはなりません。

**内容が事実と違う**
→ 「1日目は70kmではなく62kmです。直してください」と正すだけです。
AIは自分では気づけないので、こちらから言わないと直りません。

**やり直したい**
→ 「今のは一度忘れて、最初から作り直してください」で仕切り直せます。
ぐちゃぐちゃになったら、新しい会話を開いてプロンプトを貼り直すのが一番早いです。

**上限ですと言われた**
→ プランごとに使える量が決まっています。時間をおいてから続きをやれば大丈夫です。
会話は消えないので、あとから同じ会話に戻れます。
