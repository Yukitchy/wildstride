# 06 これだけは守る

**このファイルで分かること**
AIで資料を作るときに、絶対に踏んではいけない4つの線。
デザインの好みの話ではなく、**ガイドとしての信用が飛ぶかどうか**の話です。
このキットで唯一、必ず読んでほしいファイルです。

---

## なぜこの話が要るのか

AIは、頼めば何でも作ります。**あなたが持っていないものまで作ります。**

「利用者の声を入れて」と言えば、実在しない参加者の感想を、実在するかのように書きます。
「市場規模を出して」と言えば、それらしい数字を出します。
悪意はありません。ただ、埋めるのが仕事だと思っているだけです。

問題は、それを**受け取った人が本物だと思う**ことです。
一度でもバレたら、そのあと出す本物の実績まで疑われます。
ツアー業は口コミと信用で回る仕事なので、ここは他の業種より重い。

---

## 1. 実在しない利用者の声を、本物のように見せない

**やってはいけないこと**
- 参加していない人の感想を作る
- 実在する人の名前を、本人の許可なく使う
- 「オーストラリア・M様（52歳）」のような、いかにも実在しそうな架空の人物を作る

**やっていいこと**
- 実際にもらった感想を、本人に確認したうえで載せる
- 掲載場所の見本として、**「※イメージです」と本文と同じ大きさで書いた**枠を置く

「※イメージです」を小さい字で隅に書くのは**やったことになりません**。
本文と同じ大きさで、感想のすぐ隣に書いてください。読まれる大きさでなければ意味がない。

**理由**：架空の感想は、景品表示法の観点でも問題になり得ます。
それ以前に、あなたのツアーに本当に良い体験をした人がいるなら、
その人の実際の一言のほうが、作った文章より確実に強いです。

**プロンプトに毎回入れる一行**
```
実在しない利用者の感想や導入事例を書かないでください。
枠だけが必要な場合は「※ここに実際の感想が入ります」と本文と同じ大きさで書いてください。
```

---

## 2. 売上・市場規模・ダウンロード数の予測を作らない

**やってはいけないこと**
- 「初年度で年商◯◯万円が見込めます」
- 「インバウンドのサイクルツーリズム市場は◯◯億円規模」
- 「導入すれば予約が◯%増えます」

これらは、AIに頼めば一瞬で、しかも堂々と出てきます。**全部、根拠がありません。**

**理由**：提案を受け取る側は、その業界のプロです。
数字を1つ検証されて根拠がないと分かった瞬間に、**その資料全体が信用されなくなります**。
提案は、通らないのが失敗ではなく、信用を落とすのが失敗です。

数字を出したいなら、**自分が実際に持っている数字**だけを使ってください。
去年ガイドした本数、リピート率、ゲストの出身国の内訳。これは強いです。持っているものだから。

**プロンプトに毎回入れる一行**
```
売上予測、市場規模、集客数の見込みなど、根拠のない数字を一切作らないでください。
必要だと思っても書かないでください。
```

---

## 3. 他社の情報は、必ず公式サイトで確認して出典を書く

料金比較や競合の一覧を作らせると、AIはそれらしい表を出します。
**その数字は古いか、そもそも間違っています。** AIが学習した時点の情報だからです。
料金は変わります。プラン名も変わります。サービス自体が終わっていることもあります。

**やること**
1. AIには「比較の枠だけ」を作らせる
2. 各社の公式サイトを**自分で開いて**、数字を確認する
3. 確認した日付と、確認したページを表に書き添える

```
料金: 12,000円（2026年5月10日 公式サイトにて確認）
```

この一行があるだけで、資料の信用度がまるで変わります。
逆に出典のない比較表は、詳しい人ほど信用しません。

**プロンプトに毎回入れる一行**
```
他社の料金や条件は、私が本文に書いた情報だけを使ってください。
私が渡していない数字は「【要確認】」と空欄にしてください。私が公式サイトで確認して埋めます。
```

---

## 4. 数字と固有名詞は、必ず自分で確認する

AIが最も間違えるのがこの2つです。しかも、間違え方が自然なので気づきにくい。

**特に危ないもの**

| 種類 | 例 | なぜ危ないか |
|---|---|---|
| 距離・標高 | 「四国カルストの標高1,400m」 | それらしい数字を出してくる。ゲストの体力計画に直結します |
| 営業時間・定休日 | 「この食堂は水曜定休」 | 変わっています。ツアー中に閉まっていたら実害が出ます |
| 地名・施設名の表記 | 漢字の間違い、旧名称 | 地元の人が読むと一発で分かります |
| 英語の地名表記 | ローマ字の揺れ | ゲストが検索できなくなります |
| 交通機関の時刻 | 「最終は18時台」 | 帰れなくなります。これが一番怖い |

**やること**
出す前に、**数字と固有名詞だけを拾って一覧にし、上から確認する。**
これはAIに手伝ってもらえます。

```
このページに出てくる数字と固有名詞を、すべて一覧にしてください。
私が一つずつ確認します。あなたが確認する必要はありません。
```

これで確認漏れがなくなります。5分の作業です。

**理由**：ガイドの資料は、読み物ではなく**ゲストが行動の判断に使うもの**です。
間違った時刻や標高は、そのまま現地でのトラブルになります。
これはコースの下見と同じで、省いていい工程ではありません。

---

## まとめ：AIに任せていいもの / ダメなもの

| 任せていい | 自分でやる |
|---|---|
| 構成を考える | 事実を確認する |
| 文章を整える | 数字を確認する |
| 英語にする | 固有名詞を確認する |
| 見た目を作る | 何を載せるか決める |
| 案を3つ出す | どの案にするか決める |
| 弱点を指摘させる | 最後にOKを出す |

右の列は、あなたにしかできません。
そして右の列をちゃんとやっていれば、左の列をAIに全部任せても、資料は嘘をつきません。

**最後にOKを出すのは、いつも自分です。**
ツアー中に前を走るのがガイドであるのと、同じことです。
