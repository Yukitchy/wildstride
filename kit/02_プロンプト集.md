# 02 プロンプト集 — そのまま貼れる5本

**このファイルで分かること**
用途別のコピペ用プロンプト5本。どれも**そのまま貼れば動く完成品**です。
`【ここを書き換える】` だけ自分の内容に差し替えてください。それ以外はいじらなくて構いません。

毎回、**新しい会話**を開いてから貼ってください。1つの作りものにつき1つの会話です。

---

## 1. ツアーの記録ページを作る（ゲストに渡すもの）

**使いどころ**：ツアーが終わった当日か翌日。解散後にゲストへ送る一枚。
`01_まず試してみる.md` の完全版です。写真の扱いと英語版が増えています。

```
あなたは旅の記録を1枚のWebページにまとめるのが得意なデザイナーです。
私は自転車のアドベンチャーツアーを本業でガイドしています。

終わったばかりのツアーの記録ページを、ゲストに渡せる形で1枚作ってください。
アーティファクト（会話の横に表示されるページ）として出してください。

## ツアーの情報
- ツアー名: 【ここを書き換える】
- 日程と日数: 【ここを書き換える】
- 日ごとのルートと距離: 【ここを書き換える：例 Day1 尾道→今治 70km / Day2 ...】
- 総距離と総獲得標高: 【ここを書き換える。分からない項目は「不明」と書いてください】
- ゲスト: 【ここを書き換える：例 オーストラリア2名・シンガポール1名】
- 各日の出来事（箇条書きで構いません）: 【ここを書き換える】
- このツアーで一番伝えたい一言: 【ここを書き換える】

## 構成
1. タイトルと日付、総距離
2. ルート全体の要約（3〜4行）
3. 日ごとの記録（事実 → その日の情景の順で、各日3〜5行）
4. 締めの一言（ガイドである私からゲストへ）
5. 最後に、写真を貼るための空きスペースを日ごとに用意し、
   「ここに◯日目の写真」とグレーの枠で示しておいてください

## 言語
日本語版を作ってから、同じ内容の英語版もページ内に用意し、
右上のボタンで日本語と英語を切り替えられるようにしてください。
英語は観光ガイドの実務で通じる自然な英語にしてください。直訳にしないでください。

## 守ってほしいこと
- 私が渡していない数字（標高、気温、費用、時刻など）を作らないでください。
  必要なら空欄にして「要確認」と書いてください
- 地名や施設名は、私が書いたとおりの表記を使ってください
- 見た目: 文字は左揃え基本、色は3〜4色まで、紫→青のグラデーションは使わない、
  見出しは本文の2倍以上、見出しに絵文字を使わない、スマホ縦持ちで読みやすく
```

**出たあとの追い足し**
- `2日目が薄いです。雨で予定を変えた話を中心に書き直してください。`
- `英語版の言い回しが硬いです。もう少し口語寄りにしてください。`
- `印刷して紙で渡したいので、白黒でも読める配色に変えてください。`

## 2. ツアーのしおり・案内を作る（ツアー前にゲストへ送る）

**使いどころ**：予約が確定してから出発の1〜2週間前。日英併記。
これはゲストの不安を減らすためのもので、格好よさより**抜けがないこと**が優先です。

```
あなたはアドベンチャーツアーの実務に詳しいアシスタントです。
私は自転車のマルチデイツアーをガイドしていて、参加が決まったゲストに
出発前の案内（しおり）を送りたいです。日本語と英語を併記で作ってください。
アーティファクトとして1枚のページで出してください。

## ツアーの情報
- ツアー名: 【ここを書き換える】
- 日程: 【ここを書き換える】
- 集合場所と時刻: 【ここを書き換える】
- 解散場所と時刻: 【ここを書き換える】
- 日ごとの行程と距離・獲得標高: 【ここを書き換える】
- 宿泊先: 【ここを書き換える】
- 使う自転車: 【ここを書き換える：例 グラベルロード、こちらで用意 / 持ち込み可】
- 想定される路面と交通量: 【ここを書き換える】
- 含まれるもの / 含まれないもの: 【ここを書き換える】
- ゲストの出身国と人数: 【ここを書き換える】
- 想定される季節の気候: 【ここを書き換える】

## 入れてほしい項目
1. ツアーの概要（1段落）
2. 日ごとの行程表（表で。距離・獲得標高・宿泊地・その日の見どころ）
3. 持ち物リスト（必ず要るもの / あると良いもの、に分けて）
4. 服装の目安（上記の気候にもとづいて）
5. 体力の目安（毎日どのくらい走るか、坂はどの程度か、正直に）
6. 当日の流れ（朝の集合から夜まで、時間の目安つき）
7. 緊急時の連絡先とサポート体制 → ここは空欄にして私が埋めます
8. よくある質問（訪日が初めての海外ゲストが不安に思うことを想定して8問前後）

## 言語
各項目を「日本語 → 英語」の順で並べてください。左右に並べず、上下に重ねてください
（スマホで読むゲストが多いためです）。
英語は日本の交通ルールや文化的な前提を知らない人にも通じるよう、必要なら1行補ってください。

## 守ってほしいこと
- 私が渡していない事実（宿の設備、店の営業時間、レンタル料金など）を作らないでください。
  必要な項目は「【要確認】」と書いて空欄にしてください。私が調べて埋めます
- 危険や大変さを盛らないでください。同時に、隠さないでください。ゲストが判断できる書き方に
- 見た目: 文字は左揃え、色は3〜4色まで、見出しに絵文字を使わない、印刷しても読める濃さ
```

**出たあとの追い足し**
- `よくある質問に「自転車が壊れたらどうなるか」と「体力がもたなかったらどうなるか」を足してください。`
- `持ち物リストを、機内持ち込みで来る人を想定した内容に寄せてください。`
- `【要確認】の箇所だけ一覧にして出してください。私が埋めます。`

## 3. 自分のツアーの紹介ページ（LP）を作る

**使いどころ**：申し込みの入口にする1枚。予約サイトの説明文の下書きにも使えます。

```
あなたはアウトドア・アドベンチャー分野に詳しいWebデザイナー兼コピーライターです。
私が主催している自転車のマルチデイツアーの紹介ページ（LP）を1枚作ってください。
アーティファクトとして出してください。

## ツアーの情報
- ツアー名: 【ここを書き換える】
- 走る土地と全体像: 【ここを書き換える：例 瀬戸内から四国山地を越えて太平洋まで、7日490km】
- 日ごとの行程: 【ここを書き換える】
- 参加できる人の目安: 【ここを書き換える：例 1日60km前後を続けて走れる人。競技経験は不要】
- このツアーでしか味わえないこと3つ: 【ここを書き換える】
- 私がガイドとして大事にしていること: 【ここを書き換える】
- 想定するお客さん: 【ここを書き換える：例 欧米・豪州から来る40〜60代のサイクリスト】
- 料金と含まれるもの: 【ここを書き換える。まだ決まっていなければ「未定」と書いてください】

## 構成（この順で）
1. 一番上：この旅が何なのかが3秒で分かる一行と、土地の情景が浮かぶ短い文
2. どんな旅か（3〜4段落）
3. 日ごとの行程（縦に流れる形で）
4. 参加できる人の目安と、体力・装備の前提を正直に
5. 含まれるもの / 含まれないもの
6. ガイドである私について
7. 申し込みへの導線 → ボタンだけ置いて、リンク先は空欄にしてください

## 守ってほしいこと
- 私が渡していない事実を作らないでください。特に料金、定員、開催日、実績の数字
- 実在しない参加者の感想を書かないでください。感想の欄が必要なら、
  枠だけ作って「※ここに実際の感想が入ります」と本文と同じ大きさで書いてください
- 「一生に一度の」「圧倒的な」のような盛った言葉を使わないでください。
  土地と行程の具体で読ませてください
- 見た目: 文字は左揃え基本、色は3〜4色・書体は2種まで、紫→青のグラデーションは使わない、
  角丸を全部同じにしない、見出しは本文の2倍以上、見出しに絵文字を使わない、
  スマホ縦持ちを最優先、明るい画面でも暗い画面でも読めること
```

**出たあとの追い足し**
- `一番上の一行を、別の切り口で5案出してください。選ぶのは私がやります。`
- `全体的に説明が多いです。3割削って、削ったぶんを情景に回してください。`
- `海外のゲストが読む前提で、英語版も切り替えられるようにしてください。`

## 4. 誰かへの提案資料を作る

**使いどころ**：宿・自治体・観光協会・機材メーカー・他のガイドに何かを持ちかけるとき。
ユウキが Wildstride の提案ページを作ったときと同じ型です。

```
あなたは提案資料を組み立てるのが得意な人です。
私は自転車のアドベンチャーツアーを本業でガイドしています。
ある相手に提案を持ちかけたいので、1枚で読み切れる提案ページを作ってください。
アーティファクトとして出してください。

## 前提
- 提案する相手: 【ここを書き換える：例 しまなみ海道沿いの宿のオーナー】
- 相手が今困っていると私が見ていること: 【ここを書き換える】
- 私が提案したいこと: 【ここを書き換える】
- それで相手に起きる良いこと: 【ここを書き換える】
- 私の側の実績・できること: 【ここを書き換える】
- 相手にお願いしたいこと（次の一歩）: 【ここを書き換える：例 一度30分だけ話す時間をください】

## 構成（この順で）
1. 相手の困りごと（相手の言葉で。私の売りたいものから始めない）
2. その原因を私はこう見ている
3. 提案の中身
4. どう使うか・どう回るか（具体的な流れで）
5. 相手にとっての損得（お金だけでなく手間の増減も）
6. 私について
7. 次の一歩（相手が今日できる、小さくて具体的な一つ）

## 絶対に守ってほしいこと
- 売上予測、市場規模、集客数の見込みなど、根拠のない数字を一切作らないでください。
  必要だと思っても書かないでください
- 実在しない利用者の感想・導入事例を書かないでください
- 他社の料金や条件に触れる場合は、私が本文に書いた情報だけを使い、
  出典（どこで確認したか）を明記してください。私が渡していない料金は「【要確認】」としてください
- 断定を避けるべき箇所は「〜と考えています」と私の見立てだと分かる書き方にしてください

## その他
- 相手は忙しいので、上から3画面ぶん読めば要点が伝わるようにしてください
- 見た目: 文字は左揃え、色は3〜4色まで、見出しは本文の2倍以上、見出しに絵文字を使わない、
  スマホでも読める、印刷しても崩れない
```

**出たあとの追い足し**
- `相手の立場から、この提案の弱いところを5つ挙げて容赦なく指摘してください。そのあと直してください。`
- `1の困りごとが私の想像に寄りすぎています。断定をやめて、質問の形に変えてください。`
- `【要確認】の箇所を一覧にしてください。私が公式サイトで確認して埋めます。`

## 5. 写真からツアーのハイライト記事を作る

**使いどころ**：ツアー後のSNS・ブログ。写真を選ぶところまでやってしまいたいとき。
これは**写真をアップロードしてから**使います。会話の入力欄のクリップの印から、
写真を10〜30枚まとめて上げてください（一度に上がらなければ数回に分けてください）。

```
アップロードした写真は、私がガイドした自転車ツアーで撮ったものです。
私は自転車のアドベンチャーツアーを本業でガイドしています。

まず、写真を1枚ずつ見て、何が写っているかを短く書き出してください。
そのうえで、この一連の写真からハイライト記事を作ってください。

## ツアーの情報
- ツアー名: 【ここを書き換える】
- 日程と行程: 【ここを書き換える】
- 写真の順番: 【ここを書き換える：例 撮影順に並んでいます / 順不同です】

## やってほしいこと
1. 写真を1枚ずつ、写っているもの・時間帯・場所の雰囲気を1行ずつで書き出す
2. そのうち、記事に使うべき8枚を選び、選んだ理由を1行ずつ添える
3. 選んだ8枚の順に沿って、800〜1200字のハイライト記事を書く
4. 各写真に添えるキャプションを1〜2文ずつ、日本語と英語で
5. SNS投稿用に、150字以内の短い版も1つ

## 守ってほしいこと
- 写真から読み取れないこと（地名、店名、人の名前、天気の理由など）を推測で書かないでください。
  分からないものは「場所不明」と書いてください。私が埋めます
- 私が書いていない出来事を作らないでください
- 文章は私（ガイド）の一人称で、静かな調子で。感嘆符を多用しないでください
```

**出たあとの追い足し**
- `3枚目の場所は来島海峡大橋です。この情報を反映して書き直してください。`
- `記事が説明的です。読んだ人がその場の音や風を想像できる書き方にしてください。`
- `英語のキャプションだけ、もう少し短く、写真の邪魔にならない長さにしてください。`

## 5本に共通する使いかたのコツ

- **一発で決めようとしない。** 出す → 直す → 直す、が普通です。3回目くらいから良くなります。
- **「3案出してください」は強い。** 1つだけ出させると平凡なものが来ます。
- **「容赦なくダメ出しして」も強い。** 褒めさせず、壊させてから直すと質が上がります（詳しくは `03_作り方の型.md`）。
- **事実は必ずこちらから渡す。** 渡さない事実は、AIが埋めてしまうことがあります。
- **会話を分ける。** 記録ページの会話でしおりを作らない。混ざると精度が落ちます。
