# 再現キット — ガイドが自分でツアーの資料をつくる

**このファイルで分かること**
このキットが何なのか、何が作れるようになるのか、どこから読めばいいのか。
読むだけの資料ではなく、上から順にやれば手が動く道具として作っています。

---

## これは何か

ユウキ（秋葉原でアニメツアーをやっているガイドです）が、Claude というAIと一緒に
「自転車のマルチデイツアーの記録アプリ」と「その提案ページ」を作りました。
そのときにやったことを、masaya さんが**自分のツアーを題材にそのまま再現できる形**にほどいたものです。

エンジニア向けではありません。ターミナルもコマンドもGitも出てきません。
ブラウザで Claude を開いて、このキットのプロンプト（AIへの指示文）を貼り付ける。それだけです。

> **プロンプト**＝AIに渡す指示文のこと。この先ずっと出てきます。

---

## 実物

先に見てもらったほうが早いです。スマホでも開きます。

- **デモアプリ Wildstride** — https://yukitchy.github.io/wildstride/app/
  尾道→しまなみ海道→松山→内子→四国カルスト→四万十川→高知の7日490km。
  ルート再生アニメ、標高プロファイル連動、地図ピンに写真・動画36点、Day別アルバム、
  ガイド用/ゲスト用を切り替えるブリーフィング、完走記録カード、日英切替。

- **提案ページ（LP）** — https://yukitchy.github.io/wildstride/
  困りごと → 改善提案 → アプリ説明 → 使い方 → 料金比較 → 利用者の声 → 一緒にやりたいこと。

この2つとも、コードを書ける人が何日もかけたものではなく、
**AIに指示を出しながら会話で組み上げたもの**です。だから再現できます。

> **LP**＝ランディングページ。1枚で説明しきる縦長のWebページのこと。

## 何が作れるようになるか

このキットを一周すると、こういうものが自分で出せるようになります。

| 作れるもの | 誰に渡すか | どのくらいで |
|---|---|---|
| ツアーの記録ページ（1枚） | 走り終えたゲスト | 5〜10分 |
| ツアーのしおり・案内（日英併記） | ツアー前のゲスト | 15〜30分 |
| 自分のツアーの紹介ページ（LP） | 見込みのお客さん | 半日 |
| 誰かへの提案資料 | 取引先・宿・自治体 | 半日〜1日 |
| 写真からのハイライト記事 | SNS・ブログ | 10分 |

## 必要なもの

- ブラウザ（スマホでもPCでも可）
- Claude のアカウント（https://claude.ai）
- 題材にする自分のツアーの記憶。メモがあればなお良し

それだけです。ソフトのインストールも、支払い情報の入力もこのキットでは求めません。

Claude はプランによって使える機能や使える量が違います。
無料のままでもこのキットの内容はひととおり試せますが、途中で「今は上限です」と止まることがあります。
そのときは時間をおいてから続きをやれば大丈夫です。

---

## どこから読むか

**まずは `01_まず試してみる.md` だけ開いてください。** 他は後回しで構いません。
最初の1本が出てから読むほうが、全部が腑に落ちます。

1. **`01_まず試してみる.md`** — 5分で1枚。直近のツアー1本を記録ページにする
2. **`02_プロンプト集.md`** — そのまま貼れる指示文5本。ここが本体
3. **`03_作り方の型.md`** — 本気のものを作るときの進め方（5人×3周）
4. **`04_デザインの決めごと.md`** — 「AIが作ったっぽさ」を消すための具体ルール
5. **`05_できたものを人に見せる.md`** — できたものを人に渡す3つの方法
6. **`06_これだけは守る.md`** — 嘘をつかないための線引き。**ここだけは必ず読んでください**

## 一つだけ先に言っておくと

AIは平気で間違えます。それも、堂々と自信たっぷりに間違えます。
距離も、標高も、店の営業時間も、他社の料金も、実在しない数字を書いてきます。

だから **数字と固有名詞は自分の目で確認する**。
ガイドが自分でルートを下見するのと同じで、これは省けません。
詳しくは `06_これだけは守る.md` に書きました。

そのぶん、構成を考える・文章を整える・英語にする・見た目を作る、
このあたりは驚くほど速いです。得意なところだけ任せるのが一番うまくいきます。
